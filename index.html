Methodology

Ship data (AIS)

The reference site hormuz.data-tracking.net collects real AIS transponder data roughly every 30 minutes, counts strait crossings and estimates oil exports from tanker deadweight. This site currently shows simulated demo data because no AIS API key is configured.

How to connect a live AIS feed

To go live, sign up for an AIS provider (e.g. AISStream.io or MarineTraffic), then:

// in app.js — replace the demo loader: const AIS_API_KEY = "YOUR_KEY_HERE"; // fetch("https://stream.aisstream.io/v0/stream", { ... }) // map live fields: name, ship_type, flag, dwt, lat, lon, cog, sog

Live mode must keep the LIVE badge, a per-panel "last updated" timestamp, and the provider's attribution requirements.

Satellite imagery

There is no public "live satellite" feed. The Satellite tab uses Esri World Imagery, a mosaic basemap compiled from imagery that is typically months old. Free recent imagery (Sentinel-2, ~5–10 day revisit; Landsat, ~8–16 days) is available via Sentinel Hub EO Browser. Tasked high-resolution imagery is commercial and restricted.

What this site does not do

No real-time tracking of military units or facilities. The locations directory lists only the Strait of Hormuz chokepoint and major cities/islands from public geographic references.

Oil estimates

Demo oil estimates are illustrative only. Real methodology: estimate cargo from tanker DWT class × assumed load factor, summed over outbound laden tankers per 24h (see the reference site's methodology page).
